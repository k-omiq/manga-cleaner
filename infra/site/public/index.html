Manga Cleaner

Remove Japanese text from manga pages, on your own machine.

It finds speech bubbles and free text, keeps only the Japanese ones, fits masks at native resolution, and cleans each region with the lightest engine that can do the job. No account, no upload, no Python.

What it does

Automatic pipeline

Detect, gate to Japanese script, fit masks, route to an engine, clean, composite. One pass per page.

Six manual tools

Auto Clean, Brush, Shapes, AI Mask Brush, Content-Aware Fill, and Clone / Heal, for anything the pass missed.

Every region is a layer

Each clean records its engine, parameters, and timing. Re-run it, delete it, undo it. Nothing is baked in.

Long-strip webtoons

Virtual stitching, content-minimum splitting, and bounded-memory streaming across joins.

Pixel-exact export

Untouched pixels stay bit-identical. Colour mode, bit depth, ICC profile, and metadata carry through.

Formats that survive

PNG, TIFF, and layered PSD per page, a mask file beside each page on request, or a chapter as CBZ.

Runs on your hardware

Providers are picked per model from real detection and benchmarks, and can be overridden in Settings.

Nothing leaves the machine

No account and no upload. Model weights are fetched once, verified by SHA-256, and then used offline.

Install

Download the installer above: a .dmg for macOS on Apple Silicon, a -setup.exe for Windows x64. Both are built and signed by the release workflow, and the app updates itself from cryptographically signed manifests.

Model weights and the inference runtime are not bundled, which keeps the installer small and respects weight provenance. On first launch the app offers to download the ONNX Runtime (about 32 MB on macOS, about 200 MB on Windows) plus the five required model weights (about 317 MB in total). Anything you decline can be fetched later from Settings › Models. An optional Japanese text reader (about 460 MB) can be added there too: it recovers roughly 5% of balloons the script gate cannot read.

This is a beta. The pipeline runs a page end to end and the export contract is asserted by tests, but manga-LaMa can still leave faint marks inside a bubble, quality metrics need tuning on outline-heavy regions, and Windows and Linux figures are unmeasured. Keep your originals. Report anything you find on GitHub.

Build from source

You need a stable Rust toolchain, Node.js 20 or newer, and the Tauri 2 system dependencies for your platform. The repository README carries the full sequence: install dependencies, fetch the runtime, fetch the pinned weights, then npx tauri build.

Manga Cleaner is released under the GPL-3.0-only licence, which follows from comic_text_detector, the model that supplies the per-pixel text masks. Complete corresponding source lives at github.com/k-omiq/manga-cleaner.
