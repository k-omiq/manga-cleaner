# Repeated inpainting over cleaned regions

Analysis target: `codex/cloud-integration` at `f0e4af9`. Reference: Koharu at `external/koharu`, pinned to `c697b31eb1de016d9272743a2973f0e6a67eae6c`. The two supplied screen recordings are visual examples, not specifications or instructions: the first shows repeated Remove strokes preserving the hand and its outlines; the second shows our LaMa edits leaving a broad gray area and later overlapping edits exposing fragments near patch boundaries.

## Finding

Koharu's manual Remove stroke becomes a transient grayscale mask. Its inpainting stage overlays the existing Cleanup RGBA layer on the original page **before** preparing model crops; a manual stroke runs even when a Cleanup layer already exists. It then overwrites only the newly masked pixels in that same Cleanup layer and makes those texels opaque. The relevant path is `external/koharu/crates/koharu-app/src/commands/canvas.rs:352-405,414-485` and `external/koharu/crates/koharu-pipeline/src/stages/inpainting.rs:105-121,430-479,543-584,306-366`.

Our AI mask brush creates a new region for every stroke (`src/lib/editor/drawing.svelte.js:224-290`). The native path decodes the original page, fits the stroke on that raw page, and passes it to LaMa or the selected engine (`src-tauri/src/region.rs:838-855,1012-1068`). Previous patches are applied only later for preview/export by `crates/cleaner-core/src/composite.rs:37-92`. Paint and clone tools already read the visible composite through `composite_region` (`src-tauri/src/region.rs:1244-1260`; `crates/cleaner-core/src/paint/mod.rs:120-137,208-241`). Thus the LaMa crop for a second AI stroke can contain lettering from the raw scan in areas Koharu would show as cleaned. The model can carry those marks into its output. This source mismatch is proven by code; assigning every visible artifact in the recording to it requires the reproduction tests below.

The model name alone does not establish identical inference. Koharu loads `mayocream/lama-manga` SafeTensors with Torch (`external/koharu/crates/koharu-ml/src/lama/mod.rs:16-49`) and uses its own crop/keep-unmasked preprocessing (`external/koharu/crates/koharu-ml/src/lama/processor.rs:28-143`). We load `mayocream/lama-manga-onnx` through ONNX Runtime (`src-tauri/src/weights.rs:220-228`; `crates/cleaner-core/src/engines/lama.rs:9-50`) with fixed 512-pixel tiles, a model hole, and an isolation ramp. Confirm numerical equivalence with identical crop/mask inputs before attributing differences to weights or replacing the model pipeline. Koharu also offers AOT and RORem, which our app does not; both apps offer FLUX.2 Klein through different runtimes and mask conditioning. This plan targets the LaMa workflow shown in the recordings first.

## Editing behavior to implement

**New AI stroke:** read the page as currently shown, including every earlier visible automatic, AI, brush, or clone patch. Write only the new mask. This applies to partial/full overlap and to a neighboring stroke whose model context crosses the earlier patch, even if the masks do not touch.

**Try again or engine change on an existing mask:** read only visible patches below that mask's stored order. Exclude its previous pixels and any newer patches. Replace the old result atomically on success; leave it untouched on failure. A user who wants to refine the current result draws a new stroke. The UI should explain this distinction beside the two actions.

**Changing an earlier patch:** treat later results as committed snapshots, not as live procedural layers. If deleting, restoring, hiding, or rerunning A changes pixels that B read, mark B **Needs review**. Let the user Keep result, Rebuild from current page, or Undo the change. Do not regenerate B silently or incur cloud cost. Rebuilding cloud output needs fresh consent; rebuilding several dependent local masks should run in order as one undoable operation. An unrelated edit outside B's read footprint should not warn.

The current UI has new strokes, Delete, Try again, engine choice, and undo/redo (`src/lib/editor/MaskRow.svelte`; `src/lib/editor/maskactions.svelte.js`). Delete is a soft delete (`src-tauri/src/library.rs:1501-1535`). Arbitrary patch reorder is not currently exposed, though the same dependency rule should apply if it is added later.

## Real-world action and failure matrix

| Situation | Failure to prevent | Behavior or recovery |
| --- | --- | --- |
| Draw B partly or fully over cleaned A | Raw lettering re-enters B's model crop and appears at its edge. | Use A's visible result as B's input; inspect the exact applied mask and compare before/after at the boundary. |
| Draw B next to A, while its context window crosses A | A raw glyph can affect B even though the applied masks do not overlap. | Composite the entire model read footprint, not just B's write mask, and track that footprint as a dependency. |
| Draw B over a *bad* A result, such as a flat gray fill | Correct compositing propagates the bad fill; B cannot recover details that A removed. | Offer Try again/change engine on A, Delete A, and brush/clone repair. Explain that a new stroke refines the visible result. Do not promise that source compositing alone solves model quality. |
| Miss a tiny letter with a narrow mask or cover an outline with a broad one | Fragment survives or the model invents line art. | Show mask at full resolution; support undo and a corrected stroke. Keep model context and the committed write mask distinct so context expansion does not erase extra pixels. |
| Retry B after A, or switch B's engine | Feeding B its own output causes iterative drift; reading later layers makes the result order-dependent. | Render from B's underlay, replace B atomically, then flag newer patches only if their read input changed. |
| Press Try again on a painted or clone/heal mask | The stored patch has no replayable dab list; today's rerun falls through to the cleaning ladder (`src-tauri/src/region.rs:2850-2863`), which can surprise someone expecting the same brush action. | Label the action as an AI replacement when that is what it does, or disable it for non-replayable paint and direct the user to repaint. Preserve the old patch if they decline or rendering fails. |
| Delete/undo/restore A after B used it | A's pixels may remain baked into B's replacement or isolation edge. | Preserve B's committed bytes, flag its dependency, offer Keep/Rebuild/Undo, and restore the indicator correctly after undo/reopen. |
| Mix automatic cleanup, AI, paint, and clone | Different tools may disagree on which page they read or which result is on top. | Share compositor order for all tools: later AI reads earlier paint/clone, later paint covers AI, and retry of older AI excludes newer paint. |
| Make two fast strokes while the first renders | B reads a stale page or UI responses arrive out of order. | Queue per page or bind a page revision to each attempt; commit in gesture order. Show pending work and attach results to the gesture's page even after navigation. |
| Delete/undo/switch page while local or cloud inference is pending | A late result resurrects a mask or attaches to the wrong page. | Bind attempt to page/region/order/mask/input digests and recheck under the job lock before commit; reject stale work without changing undo history. |
| Grant cloud work, then change A, cancel, decline, or lose connection | Consent and attachment may cover different pixels, or leave a partial patch. | Prepare and attach from the same composited crop; revalidate exact digest and grant; no automatic retry or partial write. |
| Stroke at a page edge or across a longstrip join | Crops clamp incorrectly or miss patches from another source page. | Cover every intersecting source page in the read window and translate coordinates once; test both join sides and clamped edges. |
| Flat bubble, screentone, fine ink, color/gray/alpha, or dense page | A single model/crop/ramp can make gray fill, texture loss, halos, or excessive memory use. | Preserve source mode/depth/alpha outside mask; expose engine retry/manual repair; compare models on identical inputs and benchmark bounded windows. |
| Reopen or export after many edits | Cached preview, persisted order, and export can diverge. | Persist context provenance and review status; render preview and export through the same ordered compositor. Handle changed source scans explicitly. |

## P0 implementation plan

1. **Lock down the regression.** Add a deterministic two-stroke fixture in `src-tauri/src/region.rs` and core compositor tests. The raw page should contain an obvious glyph; patch A removes it; stroke B partially overlaps A. Capture the actual image and mask sent to a fake inpaint renderer. The expected second input is the visible result after A, including its cleaned pixels outside B's mask. Keep a second fixture where A is hidden. This should fail on the current AI path and pass on the paint path.

2. **Use the visible composite as the input for manual AI edits.** In `edit_with_bench`, build one immutable render source from the raw page plus relevant, visible, earlier patches in compositor order. For a new hand region, include all visible patches below its new order; for a rerun, exclude the region's current patch and include only patches below its stored order. Use that same source for `fit::page_noise_sigma`, `EdgeMap::sobel`, `fit::fit`, the chosen renderer, `quality::assess`, and the base pixels of the resulting patch. Preserve the original source digest as the raw-file identity; record a separate digest of the composited model input for debugging and cache/staleness checks. Reuse the ordering and mask semantics in `crates/cleaner-core/src/composite.rs`, rather than merging regions into one blob, so individual masks and undo continue to work. This deliberately gives **new stroke** (refine what is visible) and **Try again/change engine** (replace this mask's result) different, predictable meanings.

3. **Keep memory bounded.** Prove the behavior first with a full-page composite in tests, then implement production reads as a bounded context window using `composite_region`. The window must cover the manual mask, fit/ring samples, every LaMa tile crop or diffusion `crop_for` crop, and the write/isolation margin. Translate masks and resulting patches back to page coordinates once. The longstrip path must include visible patches from every source page intersecting the decode window, using the existing `patch_in_paint_space` translation. Reject an undersized window explicitly; never silently fall back to raw pixels. Benchmark a 4000×6000 page and a cross-join stroke before shipping.

4. **Apply the same source rule to cloud renders.** Consent preparation in `src-tauri/src/inference/consent.rs:502-560`, request preparation in `src-tauri/src/inference/service.rs:751-830`, and attachment in `:1330-1384` currently use the raw page. Make all three derive the canonical crop and hint from the identical composited underlay. Bind the exact encoded request crop digest (and relevant patch revisions) to consent, and recompute it before attachment. If an underlying visible patch changed during a remote job, reject the stale result without committing or automatically spending another attempt. Preserve the existing mask, crop, grant, and no-write-on-failure checks.

5. **Compare boundaries after the source fix.** Koharu commits only pixels whose manual mask is at least 127 and stores alpha 255 (`external/koharu/crates/koharu-pipeline/src/stages/inpainting.rs:306-319`). Our LaMa uses an isolation ramp and replacement patches. Compare the same stroke edge at 100% and 400% zoom and in flattened export. Adjust the ramp or mask only if a deterministic boundary test shows a seam or raw-text reveal; keep outside-mask samples bit-identical. Leave model choice unchanged until the same-input model comparison proves it contributes materially.

6. **Commit in gesture order.** The backend job lock serializes work, but two unawaited frontend gestures are not guaranteed to acquire it in gesture order (`src/lib/editor/DrawLayer.svelte:140-144`). Queue per page or bind a page revision to each gesture; recheck page, region, order, mask, and exact input before attachment. Reject stale local/cloud results without changing a committed patch or undo history. Show pending work and keep each gesture one undoable action.

## P1 and P2 follow-up work

**P1: dependency and recovery UX.** Store optional, versioned provenance for new patches: exact underlay/model-input digest, conservative read footprint, write mask digest, and relevant predecessor revisions. Use footprint intersection as a cheap prefilter; compare exact input digest before deciding whether B is affected. Keep old projects readable; mark provenance unknown only when an old patch is actually implicated by a prior edit. Show affected masks in the layer list and at export review. Provide Keep result, Rebuild from current page, and Undo change. Make selected mask, underlay, and before/after comparison available at high zoom.

**P2: quality and scale.** Compare Koharu and our LaMa with identical crop/mask inputs across flat bubble, screentone, fine line art, and color. Compare Koharu's thresholded opaque write with our isolation ramp, then tune only where a controlled edge test improves output. Cache bounded composites by source and visible predecessor revisions, crop, and order ceiling; measure large pages and dense edit histories without changing output.

## Verification gates

| Gate | Pass condition |
| --- | --- |
| Source input | Fake renderer receives the ordered visible underlay for A→B, neighboring context, A hidden/deleted, automatic A, paint/clone A, and B retry; B never reads its old result. |
| Pixels | For each edit, output outside its write mask equals its immediate underlay; outside the union of all masks, output equals raw. A stays unchanged outside B's mask; preview equals flattened export across alpha/depth modes. |
| Lifecycle | Rapid create, retry, engine swap, delete, undo/redo, page switch, save/reopen preserve order, pixels, and dependency indicators without resurrected or misplaced masks. |
| Cloud races | Change A after proposal, after consent, during inference, and before attach. A stale response cannot attach; failure/cancel leaves the previous patch intact and spends no unapproved retry. |
| Longstrip | Cross-join B sees A on either/both source pages; exported pixels match visible strip with no coordinate seam. |
| Visual quality | Review matched source images and stroke paths for lettering over ink, bubble, texture, and a deliberately bad first pass at normal size and 400% zoom. Record model SHA/runtime. The recordings guide review; exact replay requires their underlying source image. |
| Performance | Benchmark a 4000×6000 page and a dense page with intersecting/unrelated patches. Only intersecting buffers should be decoded; set release latency/memory budgets from the current build. |

Run targeted Rust tests with `cargo test -p cleaner-core composite` and `cargo test -p manga-cleaner region`; run the frontend seam tests with `npm test -- src/lib/editor/drawing.svelte.test.js`. Add a model-backed fixture only if model files are available, and record its model SHA and runtime. Automated assertions should test input and compositing contracts; image quality still needs the visual comparison.

This document is a plan, not an implemented fix. P0 resolves the repeated-stroke input mismatch and protects pending work; P1 is needed before claiming arbitrary edit-history safety. Bad first-pass output and model differences still need the recovery controls and controlled quality work above.
